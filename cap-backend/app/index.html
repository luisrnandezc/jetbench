SAP CAP + SAPUI5 portfolio project

JetBench

A role-based fleet and engine management foundation for aviation operators, built around organization-scoped data access and OData V4 services.

Technology

SAP CAP, CDS, OData V4, SAPUI5/OpenUI5, TypeScript, Node.js, SQLite for local development, and PostgreSQL for hosted deployment.
